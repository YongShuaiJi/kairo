# V1.6 Quickstart - API First / AI First

External clients (Web, CLI, SDK, MCP) are all clients of the same Platform API
(`/api/v1/*`). Every write carries `Idempotency-Key`, every error is the frozen
`ApiError` (branch on `code`/`category`, never on `message`).

## 0. Discover the contract (no auth)

```bash
curl -s http://127.0.0.1:18280/v3/api-docs | jq '.paths | keys'
curl -s http://127.0.0.1:18280/api/v1/schemas | jq '.errorModel'
```

## 1. CLI (`kairo-cli/target/kairo-cli.jar`)

```bash
# configure once (writes ~/.kairo/credentials)
java -jar kairo-cli.jar login --base-url http://127.0.0.1:18280 --token $KAIRO_TOKEN

# full AI lifecycle
java -jar kairo-cli.jar whoami
java -jar kairo-cli.jar discover --app app-default --env env-default --query pay
SESSION=$(java -jar kairo-cli.jar session create --app app-default --env env-default --profile SAFE | jq -r .sessionId)
java -jar kairo-cli.jar resolve --session $SESSION --query pay
java -jar kairo-cli.jar validate --session $SESSION --script fixed.groovy
java -jar kairo-cli.jar preview  --session $SESSION --target target.json
java -jar kairo-cli.jar trial    --session $SESSION --target target.json --script fixed.groovy --profile SAFE
java -jar kairo-cli.jar promote --session $SESSION --script-session <id>
java -jar kairo-cli.jar observe --operation <operationId>
java -jar kairo-cli.jar revert  --session $SESSION
```

Errors are structured JSON to stderr with non-zero exit:
`{"code":"RESOURCE_VERSION_CONFLICT","category":"CONFLICT","message":"...","retryable":true}`.

## 2. SDK (Java, `kairo-sdk`)

```java
KairoClient client = new KairoClient(
    new KairoClientConfig("http://127.0.0.1:18280", token).source("sdk"));

AutomationSession session = client.createAutomationSession(
    "ai-bot", "sdk", "app-default", "env-default", "SAFE", 600_000L, "idem-1");

EnhancementContextBundle bundle = client.resolveTargets(session.sessionId(), "pay", null);
// branch on bundle.scriptApiSurface().allowedProfile() + candidates with confidence

PreviewResult preview = client.preview(session.sessionId(), targetMap);
// trial requires the preview token/revision (echo them on apply)
Map<String,Object> trial = client.trial(session.sessionId(), targetMap, "ctx.result = 1\n",
    "SAFE", 60_000L, 1L, "idem-trial");

client.revertSession(session.sessionId());   // reliable one-click revert
Operation op = client.getOperation(trial.get("operationId").toString());
```

`KairoApiException` carries the full `ApiError`: `ex.error().category()`, `ex.code()`.

## 3. MCP Server (`kairo-mcp/target/kairo-mcp.jar`)

```bash
KAIRO_PLATFORM_URL=http://127.0.0.1:18280 KAIRO_TOKEN=$KAIRO_TOKEN \
  java -jar kairo-mcp/target/kairo-mcp.jar
# speaks JSON-RPC 2.0 over stdio
```

Tools: `whoami`, `discover_targets`, `resolve_targets`, `validate_script`,
`preview_enhancement`, `trial_enhancement` (**requires** `previewToken`+
`previewRevision` from `preview_enhancement`), `promote_trial`, `revert_session`,
`observe_operation`, `session_events`. The server uses the caller's least-privilege
token; it never stores a super-admin token.

## 4. Direct API (curl)

```bash
# create an automation session (Idempotency-Key de-duplicates)
curl -s -X POST http://127.0.0.1:18280/api/v1/automation-sessions \
  -H "Authorization: Bearer $KAIRO_TOKEN" \
  -H "Idempotency-Key: ai-session-1" \
  -H "Content-Type: application/json" \
  -d '{"caller":"ai-bot","source":"curl","applicationId":"app-default","environmentId":"env-default","requestedCapabilityProfile":"SAFE","ttlMillis":600000}'

# resolve targets -> compact EnhancementContextBundle
curl -s -X POST http://127.0.0.1:18280/api/v1/automation-sessions/$SID/resolve-targets \
  -H "Authorization: Bearer $KAIRO_TOKEN" -H "Content-Type: application/json" \
  -d '{"query":"pay"}'

# one-click revert
curl -s -X POST http://127.0.0.1:18280/api/v1/automation-sessions/$SID/revert \
  -H "Authorization: Bearer $KAIRO_TOKEN"
```

## 5. Scoped AI tokens (V1.6 §5.1)

Issue a token scoped to exactly the capabilities an AI client needs (narrows the
subject's permissions, never widens):

```bash
curl -s -X POST http://127.0.0.1:18280/api/v1/auth/tokens \
  -H "Authorization: Bearer $ADMIN_TOKEN" -H "Content-Type: application/json" \
  -d '{"username":"ai-robot","scope":["RULE_MANAGE"],"source":"mcp","maxSessions":3,"ttlSeconds":3600}'
```

Out-of-scope calls return `TOKEN_SCOPE_DENIED` (403, category=AUTHORIZATION);
exceeding `maxSessions` returns `AUTOMATION_SESSION_LIMIT_EXCEEDED` (409).
